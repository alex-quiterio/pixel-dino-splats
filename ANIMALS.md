# 🐾 Future animals

The T-Rex and the squid proved the recipe: ellipsoid shells → seeded gaussians → cel-shaded palette ramps → pixel snap. Next up, roughly in order of how much new machinery each one needs.

## Done
- [x] **T-Rex**
- [x] **Giant squid in the rain** (rig groups for arms, fins and falling rain)
- [x] **Mushroom stag** (bark grain, antler mushrooms, drifting spores, glow-orbs)
- [x] **Ginger & black cats** (two creatures in one scene, tail swish, blink)
- [x] **Elephant** (swaying trunk, flapping ears, tusks, dusty savanna)
- [x] **Stegosaurus** (back plates, spiked tail swing, grazing head dip)
- [x] **Velociraptor** (fully feathered with natural barring, folded wing-arms, frond tail, lipped snout, sickle claw tap, blink, nest of eggs)
- [x] **The night before Halloween** (carved flickering jack-o'-lanterns, haunted tree with owl and spider, graves, iron fence, ghost, bats, moon, fog)

## Same skeleton, new silhouettes (easy)
- [ ] **Triceratops**: frill and three horns; wide, low, four legs.
- [ ] **Brontosaurus**: very long neck and tail; a test for the tail-swish pose.
- [ ] **Capybara**: round, calm, supportive of other animals sitting on it.
- [ ] **Cat poses**: loaf, stretch, pounce (the sitting pair is done).
- [ ] **Frog**: squat body, big eyes; cheap and cute.

## New body plans (medium)
- [ ] **Axolotl**: feathery external gills (thin, elongated splats).
- [ ] **Octopus**: the squid's arm rig, minus the mantle; add suckers and colour-shifting skin.
- [ ] **Turtle**: domed shell with a hex-pattern colour rule.
- [ ] **Penguin**: tuxedo palette, waddle animation.
- [ ] **Fox**: tail as big as the body; two-tone fur ramps.
- [ ] **Whale**: huge, slow, with splat-spray from the blowhole.

## Needs new tricks (hard)
- [ ] **Bird in flight**: wing flap animation with motion-smear splats.
- [ ] **Butterfly**: flat translucent wings; needs rotated (non-axis-aligned) gaussians.
- [ ] **Jellyfish**: glow and see-through bell; needs additive blending in the renderer.
- [ ] **Dragon**: wings, fire breath as a splat particle system.
- [ ] **Seahorse**: curled tail spiral along a curve.
- [ ] **Peacock**: fan of eye-spot feathers, procedural patterning.

## Wild cards
- [ ] **Trilobite**: segmented, ancient, very pixel-art friendly.
- [ ] **Mammoth**: shaggy fur with long tusks.
- [ ] **Tardigrade**: a "water bear" in macro scale.
- [ ] **Dodo**: because it deserves a comeback.

## Engine upgrades the zoo will need
- Rotated gaussians (full quaternion rotation in the 3DGS export too).
- Additive/emissive blend mode for glow.
- Multi-creature scenes and a ground shadow.
- GIF / sprite-sheet animation export.
